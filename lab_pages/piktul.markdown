The Piktul/Lynx thread was the original laboratory project for ECE 4560 and has two main robot arms: a planar robot arm (Piktul) and a 3D robot arm (Lynx6). For the purpose of our course, this thread focuses on the Piktul arm.

The main documentation for this thread can be found [here](https://pvela.gatech.edu/classes/doku.php?id=manipulator:adventures).
