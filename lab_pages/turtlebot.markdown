The Turtlebot thread introduces the Robot Operating System (ROS) in Linux to perform path planning. This thread is well-suited for students interested in path planning and vision.

The main documentation for this thread can be found [here](https://pvela.gatech.edu/classes/doku.php?id=turtlebot:adventures).
