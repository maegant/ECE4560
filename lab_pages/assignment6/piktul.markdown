Conduct the [Pick N' Place](https://pvela.gatech.edu/classes/doku.php?id=manipulator:adventures) (either repetitive and/or arbitrary) module for either the Piktul or Lynx6 manipulator arm. I recommend switching over to the Lynx6 arm since it will be more interesting to use for the final project. But it also will be simpler to start with the Piktul arm for now. So the decision is up to you.
