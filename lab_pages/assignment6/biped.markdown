Complete the [Center of Mass module](https://pvela.gatech.edu/classes/doku.php?id=ece4560:biped:03com). Using this module, you should be able to compute a position where the robot is standing on only one foot, but where the center of mass is still located directly above the stance foot. This is done using our forward kinematics transformations conditioned on the stance foot. Try using this to command the biped to a balanced pose. If you've already done this, try moving on to the [Leg Optimal Control](https://pvela.gatech.edu/classes/doku.php?id=ece4560:biped:05optcntrl) module.
